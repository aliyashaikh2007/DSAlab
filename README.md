# DSA
📚 A collection of DSA in C assignments, practicals, and programs completed during my college coursework.
Data Structures & Algorithms – Practical Assignments

This repository contains my Data Structures and Algorithms practical assignments, implemented in C/C++.

The programs cover fundamental data structures and algorithms such as arrays, searching, sorting, linked lists, stacks, queues, trees, graphs, and hashing.

📚 Assignments
1. Array Operations and Searching

A program to store and manage student marks using an array.

Operations:

Insert marks of students
Delete a mark from a given position
Display all marks
Search using Linear Search
Sort the array
Search using Binary Search

Concepts: Array, Linear Search, Binary Search, Sorting

2. Roll Number Sorting System using Bubble Sort

A program to organize student roll numbers in ascending order.

Operations:

Accept roll numbers from the user
Sort roll numbers using Bubble Sort
Display sorted roll numbers
Display intermediate passes during sorting

Concepts: Array, Bubble Sort

3. Dynamic Contact List Management using Linked List

A contact management system implemented using a Singly Linked List.

Each contact contains:

Name
Phone Number

Operations:

Insert a contact at the beginning
Insert a contact at the end
Delete a contact using name
Search for a contact
Display all contacts
Demonstrate dynamic memory allocation and deallocation

Concepts: Singly Linked List, Dynamic Memory Allocation, Pointers

4. Browser Navigation System using Stack

A browser navigation system simulated using two stacks.

Operations:

Visit a new webpage
Navigate Back
Navigate Forward
Display the current webpage

The two-stack approach simulates the Back and Forward functionality of a web browser.

Concepts: Stack, LIFO, Browser Navigation

5. Hospital Patient Registration System using Queue

A hospital patient management system using a Queue.

Patients are attended in the order in which they arrive (FIFO – First In, First Out).

Each patient contains:

Patient ID
Arrival Time

Operations:

Add a patient
Attend the patient at the front
View all waiting patients
Check whether the queue is empty

Concepts: Queue, FIFO

6. Binary Search Tree Operations and Traversals

A Binary Search Tree (BST) is used to store student roll numbers.

Operations:

Add a new student record
Delete a student record using roll number
Search for a student
Display records using:
Inorder Traversal
Preorder Traversal
Postorder Traversal

Concepts: Binary Search Tree, Recursion, Tree Traversals

7. Social Network Connectivity using Graph Traversal

A social network is represented using a Graph, where:

Users are represented as nodes
Connections are represented as edges

Operations:

Add connections between users
Perform Breadth First Search (BFS)
Perform Depth First Search (DFS)

Concepts: Graph, BFS, DFS, Adjacency Representation

8. Library Book Indexing using Hashing

A library book management system using a Hash Table.

Operations:

Insert book IDs using a hash function
Search for a book ID
Handle collisions using Open Addressing with Linear Probing

Concepts: Hashing, Hash Table, Collision Handling, Linear Probing

🚀 Mini Project
Priority Queue Task Management System

A task management system that manages tasks according to their priority levels.

Features
Insert tasks with priority levels
Process the task with the highest priority first
Display all tasks currently waiting
Update the priority of an existing task

Concepts: Priority Queue, Queue, Sorting/Heap Concepts

Alternative Mini Project

A File Directory System using Tree Data Structure can also be implemented.

Features:

Create directories and subdirectories
Insert files into directories
Search for files or folders
Display the directory structure hierarchically

Concepts: Tree, Recursion, Hierarchical Data
